# The documents

Each subject lives in one file. Start with the quick start, then go to whichever answers your question.

| Read | When you want |
| --- | --- |

| [CLI.md](CLI.md) | every command, flag and refusal, and the exit codes |
| [CONFIGURATION.md](CONFIGURATION.md) | the environment variables it reads, and where the cases folder is |
| [CHECKS.md](CHECKS.md) | every check: what it reads, what it finds, its weight per goal, and how to fix it |
| [CASE-FILE.md](CASE-FILE.md) | what is in a case: `case.json`, `case.md` and the cards |
| [POLISH.md](POLISH.md) | the polish pass: what is sent, the guard, and why it is one plain request |

| [ARCHITECTURE.md](ARCHITECTURE.md) | how the parts fit, and the repository's layout |
| [TESTING.md](TESTING.md) | the suites, the fixtures, and the tests that only run where they can |
| [KNOWN-GAPS.md](KNOWN-GAPS.md) | what is not built yet, known to read wrong, or not proven |
| [CONTRIBUTING.md](CONTRIBUTING.md) | the rules a contribution meets |
